# v0-alpha-car

Control software and graphical telemetry simulator designed for steering and path planning tests of an autonomous RC/model car project.

---

## 🚀 Key Features
- Sensor data telemetry visualization
- Path planning algorithm testing suite
- PWM motor control bindings (Raspberry Pi/Arduino compatible)

---

## 🛠️ Tech Stack & Setup
- **Core Environment**: Setup instructions depend on the stack.
- Make sure to create a `.env` file for local development configs (do not push keys to git).
